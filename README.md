# Автотесты для API учебного сервиса Яндекс Самокат

Проект содержит пакет автоматизированных тестов для проверки REST API сервиса Яндекс Самокат. 

## Покрытый функционал

### 1. Создание курьера (`POST /api/v1/courier`)
* Успешное создание курьера со всеми обязательными полями (возвращает статус `201` и `{"ok": true}`).
* Запрет на создание двух абсолютно одинаковых курьеров (возвращает статус `409`).
* Запрет на создание курьера с уже существующим в системе логином (возвращает статус `409`).
* Валидация обязательных полей: невозможно создать курьера без `login` или `password` (возвращает статус `400` и текст ошибки).

### 2. Логин курьера (`POST /api/v1/courier/login`)
* Успешная авторизация курьера (возвращает статус `200` и `id` курьера).
* Валидация ошибок при передаче некорректного логина или пароля (возвращает статус `404`).
* Валидация ошибок при попытке входа под несуществующим пользователем (возвращает статус `404`).
* Проверка обязательности полей: возвращение ошибки при отсутствии поля `login` или `password` (возвращает статус `400`).

### 3. Создание заказа (`POST /api/v1/orders`)
* Реализовано через параметризацию (`@pytest.mark.parametrize`).
* Успешное создание заказа при выборе цвета `BLACK`.
* Успешное создание заказа при выборе цвета `GREY`.
* Успешное создание заказа при выборе обоих цветов сразу (`BLACK` и `GREY`).
* Успешное создание заказа, если цвет не указан совсем (пустой массив).
* Проверка структуры ответа: успешный запрос возвращает статус `201` и содержит числовое поле `track`.

### 4. Список заказов (`GET /api/v1/orders`)
* Проверка получения списка всех существующих заказов (возвращает статус `200`).
* Проверка структуры ответа: тело содержит валидный JSON-массив в ключе `orders`.

Запуск тестов: python -m pytest tests -v
